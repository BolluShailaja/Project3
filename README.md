Project 3 - SQL Data Analysis

Overview

This project focuses on analyzing an e-commerce dataset using SQL. The objective is to extract meaningful business insights by applying SQL concepts such as filtering, sorting, grouping, and aggregation. The dataset contains customer order information, product details, payment methods, order status, referral sources, and transaction values.

Objectives

- Understand and analyze structured data using SQL.
- Perform data retrieval using SELECT statements.
- Filter records using WHERE clauses.
- Sort data using ORDER BY.
- Group records using GROUP BY.
- Generate business insights using aggregate functions such as COUNT(), SUM(), and AVG().

Dataset Information

The dataset contains 1200 order records with the following attributes:

- Order ID
- Order Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

SQL Operations Performed

1. Data Exploration

- Displayed all records from the dataset.
- Verified successful data import.

2. Aggregation Analysis

- Total number of orders.
- Total revenue generated.
- Average order value.

3. Grouping Analysis

- Orders grouped by payment method.
- Orders grouped by status.
- Revenue generated by each product.
- Orders grouped by referral source.

4. Filtering and Sorting

- Retrieved delivered orders.
- Sorted orders by total price in descending order.

SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()

Results

The dataset was successfully imported into MySQL and analyzed using SQL queries. Business insights were generated regarding revenue, customer purchasing behavior, payment preferences, order status distribution, and product performance.
